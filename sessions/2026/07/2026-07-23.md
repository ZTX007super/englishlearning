# 重点反馈

1. `is off line every night since last week` → `has been going offline every night for the past week` → 持续且反复发生的问题使用现在完成进行时，`offline` 写作一个词 → 重试正确。
2. `supporter ... try to repair` → `technician ... tried to repair` → 使用准确职业词，并用过去式描述已发生的维修 → 重试正确。
3. `the problems remains` → `the problem remains` → 单数主语与 `remains` 保持一致 → 重试正确。
