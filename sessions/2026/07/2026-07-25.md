# 日常口语面试

# 学习目标

- 复习到期项目，并通过三个未提示采访问题建立熟悉话题口语表达的初步基线。

# 材料

- 来源：教师自设日常采访问题，无外部材料。
- 形式：三个 45–60 秒语音回答，主题为未来学习目标、近期解决的问题和计算机专业教育。
- 证据边界：仅保存必要转写摘要；语音转写用于内容和大致可懂度观察，不用于严格评价发音、重音或语调。

# 学习表现

- 完成内容：复习 7 个到期项目；完成 3 个未提示语音回答；针对网站问题说明完成 1 次语音重试。
- 做得较好：三个回答均切题，能给出理由或具体例子；能够解释 AI 壁纸网站的旧流程、改动和结果。
- 主要困难：学习者报告实际说话经常断续，并会在句中失去下一步内容；主谓一致、直译搭配和技术说明中的指代不够稳定。

# 结构化证据

- raw evidence_id：EV0012–EV0016
- 未提示内部量表：任务回应 4/5；组织 3/5；语法控制 3/5；词汇范围 3/5；流利度 2/5。
- revised evidence_id：EV0017、EV0018
- 重试表现：采用 problem → change → result 后组织提高到 4/5；转写文本更清楚，但学习者自述实际表达仍频繁停顿，因此流利度维持 2/5。
- 说明：以上不是 ETS 官方成绩；未评估发音、重音或语调。

# 重点反馈

1. `as a student major in computer science` → `as a student majoring in computer science` / `as a computer science major` → `major` 作动词时使用 `majoring in`，作名词时直接表示专业学生。
2. `the website give`、`the student don't` → `the website gives`、`students don't` → 即时输出中继续检查第三人称单数。
3. 技术说明先固定 `prompt-generating AI` 和 `image-generating AI`，再按 problem → change → result 展开；重试后结构明显更清楚。
