# 复习题面、首答评级与短修复

在任何复习题展示前读取本文件；已完整加载且版本未变化时沿用。排程、容量与正式提交由 tracker 执行，维护细节见 [review-protocol.md](review-protocol.md)。

## 三种复习家族与目标范围

复习家族只允许：

- `receptive_meaning`：判断目标在具体语境中的意义。
- `productive_expression`：从意义或情境主动提取指定单词、短语或搭配。
- `productive_pattern`：正确生成指定结构。

选择、词库、辨析和造句只是题型变体。每题必须声明一种目标范围：

- `exact_expression`：必须展示指定表达，只接受冻结的词形或固定变体。
- `pattern`：必须展示指定结构，语义合适的填充可以变化。
- `meaning_or_function`：判断意义或交际功能，合理等价表达可接受；目标过于宏观时转 skill probe。

文字和语音不创建重复日程，但事件记录真实 modality。文字成功不能推断口语流畅或发音；首版正式原子 SRS 不考发音。

## 三个 recipe stage

`strength_level` 与 `recipe_stage` 是两条独立轴。

### `relearn`

原语境或近似语境，允许不直接泄露答案的明显支架。

- receptive：目标词处于原/近语境，并提供唯一正确的英文释义选择。
- productive expression：限制性填空，可给首字母或小型词库。
- productive pattern：原/近语境填空并给词元，例如 `by ___ (practise)`。

### `recall`

受控题面、无答案型提示，要求独立提取。

- receptive：新短语境中用中文或简单英文说明当前词义，不给选项。
- productive expression：简单英文释义加必要语境，不给词库。
- productive pattern：新句受控改写，并给结构锚点。

### `constrained_transfer`

新语境、明确要求目标、包含真实语义限制，不能使用几乎任何答案都成立的自由造句。

- receptive：陌生语境中判断词义或用法，并指出语境依据。
- productive expression：在明确语义限制的新场景使用目标表达。
- productive pattern：在新交际意图中独立使用目标句型。

选择题或词库不能证明 recall/transfer。`contrast_drill` 只能组合真实学过、易混且词性兼容的项目；每空唯一最佳答案、每词至多一次并保留未使用干扰项，逐空评分，不能单独证明最高阶段。

## 展示前冻结与歧义门

长期 review item 应保存概念、目标词义、家族、范围、允许变体、易混项及两三个语境种子。每个实际题面展示前冻结：

- `question_instance_id`、简短题面、recipe stage 与题型；
- 唯一评分目标、预期答案或语义范围、允许变体；
- 标准提示、`invalid` 条件、content/context ID；
- 批次、lane、顺序、权重和稳定幂等 ID。

展示前检查：

1. 只有一个评分目标，并在需要时明确要求指定表达。
2. 常见合理答案已覆盖；干扰项存在唯一最佳答案。
3. 英文释义适合学习者当前水平。
4. 同批题面、语境、选项或词库不会互相泄题。
5. 当前批反馈不会暴露后一批目标。

概念重叠或会互相提示的项目不能同批；低优先级项延期。若反馈意外暴露后一批目标，受影响项目当天标记 `exposed`、延期且不评分。只有展示前已冻结且未暴露的备用项可以补位，否则少出一题。

题面未明确要求目标或存在合理未覆盖多解时，题目为 `invalid`，不得惩罚学习者。相同项目连续两次无法生成低歧义题，进入 `needs_recipe_fix`；修题不改变原评级、strength 或 due。

## 首次评级

每题分别判断：

- `language_validity`：回答整体语言是否成立；
- `target_demonstrated`：本题指定目标是否得到证明。

只有首次、独立、有效回答决定评级：

- `again`：错误、不知道、无法提取，或需要目标相关帮助。
- `hard`：最低限度正确但明显费力、不确定、自我修正，或命中唯一机械笔误例外。
- `good`：按当前 recipe 独立、正常地正确完成。
- `easy`：只允许在 constrained transfer，有可靠的高要求、流畅与确信证据；异步文字不能凭感觉判 easy。
- `invalid`：歧义、生成错误、技术故障或不可靠语音转写；不进入排程计算。

每批说明学习者可在答案后写 `?` 表示明显犹豫或费力。正确且带 `?`，或清楚自我修正后的正确答案，为 `hard`；AI不得按消息间隔猜测思考时间。

具体边界：

- 明确要求 exact expression 而学习者用了另一种正确英语：`language_validity=pass`、`target_demonstrated=not_demonstrated`、评级 `again`；说明英语本身成立。
- 未明确要求目标且存在合理替代：题目 `invalid`。
- 目标已展示时，无关的三单、冠词等小错不把项目降为 again；只有其破坏目标意义或冻结语义限制时才影响。
- receptive 只判断当前词义，不额外考输出词形。
- productive 的必要词形、屈折和结构属于目标。若拼写不是目标，且只有一个显然、不改义、无其他解释的机械笔误，可判 hard；形成另一词、存在多解或拼写本身为目标时为 again。
- 多个互斥答案未标最终选择为 again；明确最终答案时只评最终答案，明显自我修正为 hard。
- 大小写与标点只有契约明确列为目标时才影响评级。

## 短 repair

- 首次评级先锁定；提示后答对不修改该评级、stage 或长期证据。
- invalid 不惩罚；只有展示前冻结且未暴露的备用题才可替换，否则结束当前题并继续原队列。
- 英语正确但未证明目标时，先肯定表达成立，再说明本题未证明指定目标。
- 错误项最多一次最小提示和一次修复；仍不会时给最简答案或规则，要求立即重构一次后结束。
- 每课最多三个 again 项进入合并互动修复，按原到期顺序；其余给简短答案与原因，不延长主线。
- repair 只记 `guided`。
