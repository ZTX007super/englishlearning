# 网络材料选择规范

## 选择顺序

1. TOEFL 结构、题型和评分信息：只使用当前 ETS 官方页面或用户提供的官方材料。
2. 日常与学术英语：优先免费、合法、可直接访问的教育机构、大学、公共媒体和官方发布者。
3. 同等质量下，选择有音频、可靠字幕或文字稿、长度适合 8 分钟输入环节的材料。
4. 若来源需要登录、付费、地区不可用或页面已失效，立即更换，不让排障占用学习时间。

## 使用流程

1. 在开课时检查页面仍然可访问，并确认标题、发布者、日期和内容与学习目标相符。
2. 将难度控制在“约 70–85% 可理解”，允许少量新词，但不要让生词淹没主旨训练。
3. 只展示完成练习所需的短片段。优先让用户直接打开原页面收听或阅读。
4. 在会话记录中保存标题、发布者、URL、访问日期、近似 CEFR 等级和自行设计的问题。
5. 不保存完整文章、完整字幕或下载音频，除非用户拥有材料并明确要求保留。

## 新版 TOEFL 基准

- 内容结构：https://www.ets.org/toefl/test-takers/ibt/about/content.html
- 分数换算：https://www.ets.org/toefl/institutions/ibt/score-scale-update.html
- 截至 2026-07-20，目标 4.0/6.0 对应 CEFR B2，ETS 将常见旧制 80 分要求推荐映射为新版 4.0。
- 每次准备正式考试前重新核对 ETS 页面，不把本文件当作永久不变的考试公告。

## 无网络备用

使用 `assets/fallback-materials.md` 中的原创内容。把它用于词汇、阅读、复述、采访或写作，不声称它是真实音频，也不因此降低用户的完成记录。
